另以原結案日價格作共同觀察點，只檢查「買點位置」：PRICE_UP 的 74 個延後且仍能在原結案前恢復的事件，毛報酬差中位 −0.694 個百分點，最差收盤跌幅改善中位 +1.194 個百分點；其中 13 個原虧損輪毛報酬差中位 +1.509，61 個原獲利輪 −1.023。**同時存在降低下跌暴露與犧牲報酬的反證，不能只呈現前者。** 這沒有費稅、整張數、Grade、新加碼或新退出；原結案日不會成為候選賣出規則，過晚／未恢復者不填零。較短觀察期本身就可能縮小最大跌幅，不能單據此宣稱策略更安全。[共同觀察點診斷](../exports/delayed-reentry-design-20260914/fixed-anchor-diagnostics.json)。

## 唯一候選：E-REENTRY-UP-P1

在原規則本來可執行新的自動 H／L 買入時，只有以下條件**同時成立**才暫緩：

1. 決策前空手；當天沒有賣出，並已通過原買入與資金資格。
2. 最近一次有效自動完整結案的淨 ROI<0，沿用現有 `gradeLossCutPenaltyLevel>0`；不要求連虧兩次或任何 Grade／虧損幅度。
3. `tMa60Days<0`。
4. 個股價格階段為盤整、拉回前／後期或探底前／後期（raw 1／4／5／6／7）。

當日只取消這次**新自動買入**，不改原 H／L 分數、門檻與 H 優先，不藉 H→L 繞過等待。日後逐日重新判斷：MA60 Days≥0，或價格已反彈／探頂（raw 2／3／8／9）時，這個閘門不再阻擋，但仍須當日原 H／L、E-03、現金及整張數通過，才會實際買進。

這是一個每日的資格條件，**沒有保留舊訂單、到期強制買入、固定冷卻、最低價回看或永久解鎖**。某日可恢復但沒有買成，下一日轉弱仍重新等待。即使買價高於舊訊號，只要原規則與新資格通過也照規則執行，不事後加「不得買貴」條件。價格 phase 0 的資料不足情形由原技術就緒閘門處理，此候選不自行改其行為。

持股中、加碼與退出全部不變；人工反轉在正常自動結果之後依現行語意重驗，B+ 不被這個自動等待硬擋，B− 是否冗餘依正常結果判斷。獲利有效自動結案解除既有認賠旗標，零 ROI 與人工結案不改旗標；空手時不用等待獲利結案才能恢復，因此沒有循環依賴的永久鎖定。若市場條件一直不恢復，仍可能長期空手，必須列為成本，不能強制填一筆買入。

## 為何選這個首測，而非直接宣布有效

採用前景是**有限但具體**的：可利用既有價格轉折縮短或延長等待；原恢復輪不必一律等固定天數；A／B 均有原虧損輪在恢復時買得更低，也有原獲利輪不受延後或買得更低。這是跨股的價格路徑線索，不只是富邦媒單例，且有明確的等待／恢復定義。

現存障礙同樣具體：54 件技術恢復更貴、23 件晚於原结案、最長等 186 日，共同原結案觀察點的整體毛報酬差也偏負；延期是否减少實際認賠與占用，足以抵銷這些代價，尚未知道。首測的決策價值正是用完整成交、費稅、加碼、退出與 Grade 路徑驗證這項交換，而不是再統計原勝率。

本方案不是因四組平均數最高而挑出；沒有做完整候選分數選優。WAIT5 只是對照尺，舊 E-LC04 固定 15／20／30 日及 E-LC05 跳過訊號數皆已有負面結果，不重開天數校準。MA20 容易已在反彈時成立，MA60 又有明顯滯後；先測價格階段的自適應恢復，不能據此宣稱它已優於其他完整策略。

## 實作與有效性驗收

- 重用 `RollingContext` 已有認賠旗標及 T3 的價格階段／MA60 Days；不新增連虧或等待計數、schema、通用狀態欄位。候選期间維持 T3/S51 的正式版本標示，另以候選策略身分區隔；日後採用屬 S 語意變更，另按正式流程升版，不預先採用。
- 執行閘門位於原新倉资格／E-03／資金判斷之後、人工反轉之前。被阻擋時 `buyIt=false` 並清除未成交的新倉 `simRuleBuy`，不得留下 H／L 持股標記；原訊號本身仍可旁錄供解釋。
- 旁錄原可執行行動、認賠旗標、MA60 Days、價格 phase、等待原因、當日恢復原因、候選成交。等待是執行資格，不偽裝成 H 減分；H 成立時不額外產生 L，H 不成立仍沿原 L 判斷。
- 先驗邊界：現行原路徑候選會阻擋 A52、B45 個原買點；**只有最早分歧可要求精確匹配**，A27／B23 個股窗的首次 BUY→NONE 已保存。後續 97 個原買點不可當成候選必然阻擋清單；候選路徑必須獨立更新。[首次分歧清單](../exports/delayed-reentry-design-20260914/expected-first-boundaries.json)。
- 定向測試包含：phase 全部 raw 值、MA60 Days 的負／零／正、無／虧／盈／零／人工結案旗標；H／L 新倉、持股加碼、E-03、現金不足；等待後恢復但原訊號不成立、再轉弱、人工 B+／B−；完整與部分重算 Context 一致、P10 不污染正式前態。這些測試验证跨日行为与边界，不以测试行数代替有效性。

## 結果必須回答的問題

**一、是否真的降低認賠？** 報告每個固定窗口的虧損結案總額、單輪損失分布與最差輪，另列截止日未實現損失。不能靠少賣、延後認賠到截止日之後，宣稱風險減少；同時呈現總淨損益與淨 ROI。

**二、是否改善資金與時間？** 報告成本×日曆占用、平均／最長持股、等待交易日、等待中的可執行訊號數、截止仍空手或持股、投入次數／最高投入與不足。空手等待不算持股日，但必須單列，避免只因更少持股而主分變好。

**三、完整策略是否值得？** 以[實年報酬率與週期](報酬率.md#實年報酬率)、兩股群主分及三窗口共同評估；列固定結果與九年風險各自方向，不把兩者相加成新主分，也不以九年一般反向自動否決固定窗口。實際買價比較、原獲利輪是否另日進場、替代輪与錯失輪都由候選本身辨識，不把原正負標籤搬成候選收益。

**四、富邦媒究竟怎樣改變？** 從第一次真實分歧開始，逐日追認賠旗標、Grade、等待／恢復、實際買入、股數、加碼、退出及下一輪；用共同日期的資產／損益比較整段，不能將三個獨立診斷事件的改善加總。辨別「買低少賠」「買得更晚但仍賠」「反彈買貴」「沒有買成」及先前路徑效應。

## 停止、續驗與採用界線

- A 固定結果若零差異，先核對本來應有的首分歧；工程正確則不能稱規則改善。若明顯退步，先檢查全部主要正反例、等待／恢復及退出連鎖，沒有具體單一新界線便停止，不自動切 Grade、加日數或改價格階段。
- 只有 A 固定合計主分改善、至少兩窗不退，且認賠負擔（含期末未實現損失）、資金占用與兩股群沒有相反的重大代價，才具備提議同條件 B 的基礎。若結果是減少認賠但犧牲主分／年報酬，必須把幅度與代價交使用者選擇，不能自行定義已成功或把風險改善抹掉。
- A 九年用於原例與單一路徑風險；僅資料錯誤、資金失控或普遍重大意外提高其否決權重。若只有富邦媒九年改善、固定窗口不支持，不足採用。
- 後續 B、其他樣本或正式採用各自依結果另行授權；沒有自動延伸的候選網格。若最後採用，仍須當期所有正式樣本固定與全期間同版完整 Baseline、DecisionBase、S 遷移與人工操作驗證，非本次設計自動授權。
