# 版本與資料重算

## 更新時會發生什麼事

安裝新版小確幸後，通常不需要另外操作。開始更新股價時，小確幸會先檢查既有資料是否適用於新版規則：

- 資料已符合新版規則：直接進行一般股價更新。
- 資料需要重算：畫面會顯示版本更新訊息，完成後才繼續更新股價。
- 重算曾經中斷：下次更新會從未完成處繼續，不必刪除資料或重新安裝。

重算尚未完成時，盤中價格更新與十檔價格建議會暫停，以免新舊資料混用。如果其他資料作業正在進行，更新要求會排在後面，不會消失。

## 手動紀錄會保留嗎

需要重算而且股票含有手動反轉買賣或手動加碼時，小確幸會先顯示不可取消的提醒。

重算會逐筆重新確認這些紀錄：

- 仍會改變正常結果的操作會保留。
- 重算後結果已經相同的重複操作會清除。
- 因持股或交易狀態改變而無法成立的操作會清除。

完成後會顯示更新股票數；若原本有手動操作，也會分別顯示保留及兩類清除筆數。

## 如何查看版本

在右上角點選「？」開啟「參考訊息」，會看到類似以下內容：

```text
小確幸 vX.Y.Z (Build)
規則版本 Tn/Sn
```

第一行是安裝的小確幸版本；第二行是現有資料採用的計算規則。安裝版本變更不一定需要重算，只有資料計算方式改變時才會更新規則版本。

日常新增或修正股價及加權指數，只會從受影響日期往後更新，不會因此更改規則版本。盤中與收盤後的查詢時間見[歷史價格下載](週期.md#歷史價格下載)。

本文不列目前版號或逐版規則變更，實際安裝版本以 App 顯示為準。需要研究與開發細節時，另見[現行規則與版本定義](現行回測規則.md#版本與重算)。
