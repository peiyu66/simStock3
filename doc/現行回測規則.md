# 現行回測規則

本文件是目前正式回測 Baseline、股票樣本與現行規則的權威清單。它說明各規則的組成、用途、精確條件與門檻，並以「覆蓋狀態／最後實驗」記錄目前最新的檢驗現狀。

「規則目的」只說明想抓的情境，是待驗證假設，不代表已證明因果。

回測方法、實驗計畫、詳細歷史結果與已退出規則集中在[回測規則驗證](回測規則驗證.md)；歷次正式對照基準、分數與完整報告入口集中在[Baseline 歷史](Baseline歷史.md)；Grade 的評等意義與顯示方式見[選股評等](選股評等.md)。未正式採用的候選不會改寫本文件的現行條件或 Baseline。

## 規則組成與判斷順序

1. **Grade（G）**：依交易當時累積的[實年報酬率](報酬率.md#實年報酬率)、[平均持股週期](週期.md)與完成輪次，建立選股評等並供部分買入、賣出與加碼規則判斷。
2. **買入（H／L）**：空手時先判斷 H 買入規則；H 不成立才判斷 L 買入規則。H 是追高型進場，L 是承低型進場。
3. **持有後處理（S／A）**：持股時由 S 規則判斷賣出、A 規則判斷加碼；同日同時符合時，賣出優先。
4. **成交與資金（E）**：統一規定價格、手續費、稅、張數、預算與成交限制，確保 Baseline 與候選只比較規則差異。

規則代號中的 P、N、C、T、M、E 分別表示正向條件、負向條件、季節條件、成立門檻／候選資格、Grade 對映及加碼或成交執行條件。門檻涉及的自訂技術值，以[技術數值與研究原則](技術數值與研究原則.md)的定義為準。

### 為什麼採分數制

股價並不會因單一指標成立就只有一種後續：同樣的超賣、放量、均線或價格位置，在不同股票性質、行情階段、原買入路徑與持倉狀態下，可能有不同意義。因此 H、L、S、A 都不把一條簡單規則當成直接交易命令，而是當成對一個可解釋局部現象的一張讚成票或反對票；多條方向不同的規則累加、抵銷後，只有總分跨過 T 門檻才會形成買入、賣出或加碼候選。

這個架構的設計假設是：沒有一條簡單規則能在 H／L股群、所有三年窗口與不同股票樣本全部獨立有效。一條規則在某些情境偏強、在另一些情境略弱，不必然是缺陷；只要現象意義清楚、權重有限，且整套規則的回測顯示其他訊號能在不同情境互補，它仍可能是有價值的邊際證據。規則因此應先追求「單一現象、方向可解釋、小權重」，而不是把多種情境塞進一條複雜且只適配歷史樣本的完美條件。

「可由其他規則補足」不是忽略退步的理由。候選仍要檢查股群、窗口、樣本、ROI、持股週期、資金占用與個股集中度；若經常產生大幅反向結果、與其他規則重複計分，或所謂互補未在完整回測中出現，仍不應採用。效果只出現在單一股票或窗口時，外推信心較低；但若現象意義清楚、受控重播與限定反事實確認因果，且其他股票、窗口與樣本沒有實質代價或只有可接受的小代價，可以先作有限採用並明記待新樣本重驗，不因樣本少就直接丟棄已證實的局部反應。詳細的檢驗與深入準則見[分數制規則的設計觀點](回測規則驗證.md#分數制規則的設計觀點)。

Sample A／B／C／D 都只是固定且經設計選出的樣本。只要輸入、唯一變因與重跑方式受控，每個樣本取得的分數都是有效證據；即使四組同向，也只能稱為在目前特選樣本內較一致，不能稱為穩定、普遍有效或可外推，換入新樣本仍可能反轉。跨樣本反向用來限制外推與標示風險，不會使另一份受控結果失效，也不設「所有樣本與窗口不可反轉」的硬門檻。A／B 反向且現有 C／D 可用時，先完成同條件的 C／D，再綜合幅度、股群與代價決定。固定三年仍是主要採納依據；若規則目的在幫助選中股票累積至 `wow`，較強股群是優先判讀面，較弱股群的週期與資金代價則另列風險。

## 門檻讀法

表中的 `>`、`<`、`>=`、`<=` 都是程式實際使用的比較方式，等於門檻時是否成立須依符號判斷。Z 是標準分數；例如 `Z > 1.5` 表示高於近期常態 1.5 個標準差。

Grade 門檻若列三個值，順序固定為低評（damn／low／weak）、中評（none／fine）、高評（high／wow）；若列兩個值，該列會直接寫明兩組 Grade 的分界。這些門檻只改變當日規則分數，不會直接改寫股票所屬的回測股群。
