## 1. 可行性判斷

**值得進行有界的前置研究；目前尚未證明 L 買存在可穩定辨識、可成交且改善整體策略的十日低買機會。** 現行 L 規則以 KD、OSC、價格位置、量能與恢復訊號累積低接資格，但「已低到可承接」不等於「短期下跌已結束」。可檢驗的假說是：部分原可成交 L 新倉仍處於下跌延續或反彈不足的情境，由個股、決策前模擬狀態及大盤的複合條件辨識後短暫等待，可能降低實際進場成本。

## 3. 十日機會與成功的分層定義

依使用者「大致和前次一樣，如只找10日內」擬定：十日為原 L 買日後第1～10個**個股交易日**，不含原買日，也不是十個日曆日。這是本計畫的觀察範圍，不是第十日強制買入或保證最長等待十日。

1. **價格機會。** 從全部原 L 新倉出發，包括十日內沒有較低價的對照；找十日最低收盤價及全部並列日期，記第一次較低日、低價持續段、跌幅、途中反彈、先跌／先漲路徑。盤中最低價不得冒充按收盤可成交價。最低日期只作研究座標，可觀察原買日到低價區及其前後數值，不用它指定買入日或當成當日輸入。
2. **條件行為。** 查看當日可知複合條件是否在原買點成立、低價區前後解除；T／大盤可按既定日期直接重用，後續 S 不可抄原已持股路徑。條件解除不代表可買，未知前態亦不算失敗或成功。
3. **實際低買。** 候選自身逐日重播，取第一次真正符合原 H 或 L 及執行閘門的成交，不能挑其後最低日。十日內價格嚴格低於原買價才列主要低買成果；同價、買貴、H 接手、超十日、期末未買、資料未知分別揭露。H 接手另列成交型態，仍按實際價格分類。
4. **策略效益。** 低買比例與幅度不取代完整固定窗的[實年報酬率／真年報酬率](報酬率.md)、效率分數、持股週期、損益及資金占用。漏掉原獲利輪、加碼與退出改變、後續 H/L 輪次都須納入。

十日觀察不因原策略先賣出就截斷，但跨原退出日必須標記，避免把錯過整輪的晚買當成無代價改善。窗口末不足十日、缺正式行情或停牌等依引擎契約標截尾／缺口，不借下一窗口補足。完整重播保留超十日及期末未買的全部損益。相鄰起點的十日區間重疊、同一大盤日跨股共現須揭露，不能把它們都稱獨立證據。

## 4. 候選交易動作

唯一變因是新增複合條件 C：當日**空手、正常 H 經現行規則處理後未成交、原 L 已達門檻且通過正常自動買入執行閘門**，C 成立時暫緩當日 L 新倉。不是把 L 扣一票、提高五分門檻或同時更改加碼。

每天重新依候選自身前態判斷。正常 H 成立時仍優先買入（H-E01／H-E02 照常），新 C 不限制 H；H 未成立才評估 L，C 解除且當日 L 仍可成交才買入。不得保存原 L 資格稍後直接兌現，不加「跌到低於原價才可買」來機械保證低買；第十日也不強制買。若日後要改成最長等待、記住訊號或同時攔截 H，屬不同交易動作，另提版本。

持股後沿用全部現行加碼／賣出規則及 S-E01／S-E02；新 C 不更動持股 L 分數或 `lWantForAdd`。首次買進的現金、前日賣出／反轉、當日人工意圖等閘門須依正式引擎完整核對，僅 L 五分不是可成交證明。資料未成熟、缺值或非有限值不觸發新限制；涉及 OR 時逐分支明定有效性，不以未知填0。人工操作的優先及保留／冗餘／無效重驗語意不變。

特別標記起點是原 H 未達標，還是 H-E01／H-E02 擋 H 後由 L 接手，分開觀察增量與重疊；不先排掉其中一類，也不把兩種延遲的收益相加。控制與候選從各窗口起點完整重播，不能每段都重置回 Baseline。

## 5. 欄位、複合搜尋及反例

依[技術數值與研究原則](技術數值與研究原則.md)建立逐欄目錄，重用前次目錄與工具但重新判定 L 空手用途。T 包含價格／KD／OSC／均線／量能／Z值／價格路徑及既有滾動變化；S 包含決策前 Grade、連續效率、趨勢、警示、上一輪與空手狀態；M 包含同日大盤可由固定來源重建的技術數值，不只限正式投票已用欄位。每欄記公式、因果時點、成熟、缺值與去向；空手不適用的持倉欄不能湊成額外訊號。`.none` 不作新候選的正向觸發或門檻界線。

涵蓋 T／S／M／TS／TM／SM／TSM 七來源，至少兩個不同底層數值，優先二至四值。允許寬門檻、區間、AND及最多兩分支OR，每個OR分支至少兩值，整式最多四個底層值、八個比較；同欄上下界只算一值，相關表徵須揭露。先覆蓋合格雙值式，再有界擴為三／四值及OR，保留來源與形狀多樣性；不聲稱窮盡所有高階組合。

切點在 C/D 前兩窗以自然界線、粗分位及寬區間固定，不追著個案切細。使用人工植入的控制訊號驗證欄位、生成、保留及時序流程。凍結後查第三窗；若第三窗促成修改，另記版本及已參與設計，不再稱留出。後續 A/B/E 不提前看效果選式。

原P03首批的歷史範圍為「最多保存六個不同家族，優先提一個值得回測者」；此上限不適用於[現行第二批](#ld-second-batch)，第二批依證據批次選案、不預設六個。沒有固定最低案例數或95%／100%低買硬門檻。少量例、單股／單日集中、鄰近切點敏感、十日未解除與未知都明列。不用最大跌幅或自製加權分數遮蓋漏買／買貴。

**少數反例須在回測前深入分析。** 比較正例與反例的原買點、低價區及解除行為，區分無低價、太早解除、一直成立、正常資格消失及資料未知；只將已重播者稱實際成交。容許在既定粗原子內新增或替換至多兩個具機制的限制，維持上述公式大小，先列組合成本。並列原式與修正版的正例保留／流失、反例排除／殘留、新增命中、晚買及未知；移為未知或超十日不算修復。不能用股票、日期或未來結果作例外。

有廣泛合理正向線索、可解釋且無已知不可接受代價時即可凍結提測，不要求前置分析先證明成交與獲利；未能全排反例不自動淘汰。涉及後續 S 的解除，採必要的候選自身分支或完整回測解答，不為前置研究建立任意公式的全量反事實資料工程。
