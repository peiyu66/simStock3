# TWSE 無價格列解析修復

狀態：3.7.2（92）／T4/S65 已推送並更新 Latest，公開安裝資產及簽章驗證通過。下方本機候選階段的不發布限制已由使用者明確發布批准取代。來源主對話 `01a157c0-b093-70cf-8e24-55c477db90d7`。本案接續[舊庫月份銜接](舊庫歷史月份銜接修復-20261022.md)，不改策略、指標公式或既有窗口。

## 問題與已確認來源

3.7.1 更新後反覆顯示尚待補 5 個月。唯讀取得的使用者資料副本及原始回覆證實：每月有一列開、高、低、收全為 `--`，現行解析先排除該列，再因成功列數不等於回應列數而拒收整月，沒有保存來源完成紀錄。每股第一個失敗月份後停止，因此四個請求失敗卻留下五個月份。此缺口不是六個月批次限制或成功紀錄被撤銷。

官方交叉核對：裕隆 2020/03/30、鴻海 2025/07/30、京元電子 2024/04/26 均有 TWSE 暫停交易紀錄；波力-KY 2023/02/17 的每日行情及兩種零股報表均為零成交，未推測停牌原因。波力 2026/06/12 的盤中零股 39 股／7 筆／5,070 元，加盤後零股 100 股／1 筆／12,500 元，精確等於月行情 139 股／8 筆／17,570 元。[證交所交易制度](https://www.twse.com.tw/zh/products/system/trading.html)明定零股成交價不列入當日普通開高低收；成交量額統計則包含零股。這五筆是正常無 OHLC 表示，不能只憑 HTTP 或 stat OK 判定，但也不應當成來源漏價。

## 修正契約

- 非空月回應逐列分為可用價格、四個 OHLC 明確全為 `--`、異常資料。每列仍驗日期有效／同月／唯一、量額及筆數為合法非負整數。部分 OHLC 缺值、其他缺值代號、非有限值、負數、格式錯誤、跨月與重複日期仍拒收；空回應、來源錯誤不當成上市前或完整月份證據。
- 可用價格沿原公式及張數換算寫入。無 OHLC 列不新增 Trade、不填零、昨日價或零股價，也不覆寫已有有效價格。
- 無價格列的日期、原始股數、成交金額及筆數保存於既有 `twseHistoryCoverage` Data 的可選 `noPriceDays` 附記。它只供來源追查，不進入量價指標或 T／S；不新增 SwiftData schema、不改既有量價語意。舊 JSON 可直接解碼，原月份收據與舊庫銜接證據保持。
- 全月只有明確無價格列仍可確認來源已完整回覆，不代表有可計算價格或上市前證據。當月確認只到回覆中最晚日期，包含無價格日；已結束月份沿原規則確認至月底。
- 月份收據、無價格附記、原始行情與必要 dirty 一起保存，成功才完成。來源保存失敗恢復原收據／附記，待辦保留；來源已保存而後續 T／S 失敗則沿既有恢復規則續算。刪除月份來源證據時同步撤銷其無價格附記。
- 下載排程與待補計數仍共用既有月份判定。實際輸入或可靠補齊事件造成的必要 T→S 依[更新週期契約](更新週期與取消下載暫算計畫-20261021.md)處理，沒有變因不強制全重算，人工意圖照原規則保留及重驗。
