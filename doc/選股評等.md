# 選股評等

選股評等將股票截至當時的[實年報酬率](報酬率.md#實年報酬率)與[平均持股週期](週期.md)合成一個效率分數，再劃分為七個等級。它描述歷史模擬中該股與小確幸策略的適配效率，供選股及部分買賣門檻參考，不是對收盤價或未來績效的預測。

本文件說明評等本身；正式評等規則、它如何影響買賣門檻及最新檢驗狀態，見[現行回測規則](現行回測規則.md#grade-上游規則)。

## 畫面圖示速查

| 畫面圖示 | 效率分數 | 解讀 |
|---|---:|---|
| **紅底白星** | 大於 46 | 歷史模擬效率最高 |
| **紅框「2」** | 大於 39、最高 46 | 高效率 |
| **紅框「1」** | 大於 23、最高 39 | 正向效率 |
| **灰框「0」** | 尚未啟用評等 | 資料尚未成熟，不是一般的中間等級 |
| **綠框「1」** | 最低 -5、最高 23 | 效率偏弱；也可能仍有正報酬，但效率尚未超過 23 |
| **綠框「2」** | 最低 -23、低於 -5 | 虧損或持股週期造成的低效率較明顯 |
| **綠框「3」** | 低於 -23 | 歷史模擬效率最低 |

紅色代表效率較佳，綠色代表效率較弱；框內數字表示離中間狀態的程度，因此不能只看數字大小。例如紅框「1」優於綠框「1」，而綠框「3」比綠框「1」更弱。

### 灰色圖示怎麼看

- **灰框「0」**：尚未完成至少三輪買賣，且累積平均持股週期也尚未超過 360 日，所以還沒有正式評等。
- **整列文字與箭頭都是灰色**：該日早於模擬起始日，只是準備技術數值所需的歷史資料，不提供買賣或加碼操作。
- **原本應是紅星或紅／綠數字框，卻顯示深灰色**：模擬期間曾出現起始本金不足，評等可能失真，應先排除資金設定問題再解讀。
- 只有趨勢箭頭沒有顯示，不等於灰框「0」；它也可能只是價格盤整、效率變化未達門檻、趨勢正在冷卻，或資料尚不足。

## 何時開始評等

股票完成至少三輪買賣，或累積平均持股週期超過 360 日後，才啟用效率評等。在此之前一律顯示**灰框「0」**，表示資料尚未成熟；評等啟用後會改為紅色或綠色圖示，不再回到灰框「0」。

回測逐日計算買賣規則時，只使用該筆交易以前累積的結果形成當時的動態評等，不會把模擬期末評等倒套到先前交易。

## 效率分數

效率分數由實年報酬率與平均持股週期共同計算：

- 報酬率為正：效率分數＝實年報酬率 × 100 ÷ 平均持股天數。
- 報酬率為負：效率分數＝實年報酬率 × 平均持股天數 ÷ 100。

正報酬時，較高報酬與較短週期會提高分數；負報酬時，虧損愈深或套牢愈久，分數會愈低。

## 三種趨勢圖示

App 目前有三種趨勢箭頭，先依它靠近的數值判斷種類：

| 趨勢 | 靠近的數值 | 回答的問題 |
|---|---|---|
| 個股價格趨勢 | 個股成交價／收盤價 | 這支股票截至該日走到哪一段價格路徑？ |
| 加權指數趨勢 | 成交價泡泡外側，或技術檢視的「加權指數」收盤值 | 同一交易日的大盤走到哪一段價格路徑？ |
| 評等趨勢 | 選股評等 | 小確幸策略對這支股票的近期適配效率，相對長期正在改善或惡化？ |

三者都使用箭頭，但不是同一個數值。個股與加權指數描述價格；選股評等描述模擬效率。圖示本身不是直接買賣指令，正式加減分仍以[現行回測規則](現行回測規則.md)為準。

### 個股與加權指數的價格趨勢

兩種價格趨勢都以收盤價形成 20 日路徑，使用同一套九階段與圖示。方向、實心／空心表示目前路徑，淡色與原色則表示同一段的前期／後期：

| 圖示 | 階段 | 解讀 |
|---|---|---|
| 淡紅色實心右上箭頭 | 探頂前期 | 價格由本段錨點向上延伸，尚在前段 |
| 紅色實心右上箭頭 | 探頂後期 | 向上延伸已進入後段，仍不代表已到最高點 |
| 淡紅色空心右下箭頭 | 拉回前期 | 價格由本段高點回落，尚在前段 |
| 紅色空心右下箭頭 | 拉回後期 | 由高點回落已進入後段 |
| 淡綠色實心右下箭頭 | 探底前期 | 價格由本段錨點向下延伸，尚在前段 |
| 綠色實心右下箭頭 | 探底後期 | 向下延伸已進入後段，仍不代表已到最低點 |
| 淡綠色空心右上箭頭 | 反彈前期 | 價格由本段低點回升，尚在前段 |
| 綠色空心右上箭頭 | 反彈後期 | 由低點回升已進入後段 |
| 不顯示箭頭 | 盤整或資料不足 | 尚未形成可顯示的方向，或有效資料還不夠 |

「後期」表示本段相對於開始時已走得較深，不是事後找出的最高點或最低點，也不保證下一步反轉。探頂／探底以本段累積進展達凍結門檻的 `1.5` 倍切入後期；拉回／反彈以離開本段極值達門檻的 `0.75` 倍切入後期。每段使用開始時凍結的波動門檻，詳細定義見[價格路徑狀態持久化計畫](價格路徑狀態持久化計畫.md#前後期切割)。

個股價格圖示顯示該筆每日交易紀錄的個股階段；加權指數圖示只做**同一日期**的市場對照，不以前一日圖示代替。盤中若只有個股 Yahoo 當日行情、尚未有正式同日大盤資料，加權指數收盤值與圖示維持無資料。這個畫面對照與正式規則讀取「決策日前最近一個已完成市場交易日」是兩個不同用途。

### 評等趨勢

選股評等旁的趨勢圖示補充「效率最近正往哪個方向變化」。顏色表示主要趨勢，改善探頂／惡化探底的淡色與原色表示前期／後期，實心／空心則區分仍在延伸原方向，或已從本段極值反向移動：

| 圖示 | 狀態 | 解讀 |
|---|---|---|
| 橙色實心右上箭頭 | 改善預警 | 近期適配效率已明顯升高，但尚未進入改善確認 |
| 草黃色實心右下箭頭 | 惡化預警 | 近期適配效率已明顯降低，但尚未進入惡化確認 |
| 淡紅色實心右上箭頭 | 改善確認・探頂前期 | 已進入改善確認，運行高點尚未達 `+0.911888` |
| 紅色實心右上箭頭 | 改善確認・探頂後期 | 仍在尋找本段更高的趨勢值，且運行高點已達 `+0.911888` |
| 紅色空心右下箭頭 | 改善確認・拉回 | 仍屬改善確認，但已由本段運行高點回落超過 `0.3` |
| 淡綠色實心右下箭頭 | 惡化確認・探底前期 | 已進入惡化確認，運行低點尚未達 `-0.911888` |
| 綠色實心右下箭頭 | 惡化確認・探底後期 | 仍在尋找本段更低的趨勢值，且運行低點已達 `-0.911888` |
| 綠色空心右上箭頭 | 惡化確認・反彈 | 仍屬惡化確認，但已由本段運行低點回升超過 `0.3` |
| 不顯示箭頭 | 中性、確認後退回或資料不足 | 變化尚未跨過門檻、確認結束後尚未重置，或有效觀察未達 125 筆 |

選股評等與趨勢回答不同問題：

- 選股評等是截至該日累積成果形成的等級，回答「目前整體適配程度如何」。
- 趨勢比較評等背後連續效率分數的 20 筆與 125 筆指數移動平均，回答「近期相對長期正在改善還是惡化」。兩者差距大於 `+0.611888` 才顯示改善，小於 `-0.611888` 才顯示惡化；介於門檻內不顯示。
- 趨勢使用連續效率分數，不是直接比較紅星或紅／綠數字框。因此評等圖示尚未改變時，箭頭仍可能先出現；評等圖示改變後，箭頭也可能因變化趨緩而消失。
- 預警從 `±0.3` 開始；一旦進入確認，回到預警數值區不會再次顯示預警，而是先隱藏到狀態重置。
- 確認分段只使用當日以前已保存的趨勢狀態與運行高低點。改善、惡化都必須離開本段極值**超過** `0.3` 才轉為拉回／反彈；惡化反彈若單日再下降超過 `0.3`，會重新標為探底。改善沒有對稱的單日重設規則。
- 探頂／探底後期門檻 `0.911888` 是確認門檻 `0.611888` 加既有轉折幅度 `0.3`。前期沿用同方向圖示的 58% 色彩透明度，後期恢復原色；預警、拉回、反彈與冷卻不再切前後。
- 空心箭頭仍保留原確認顏色：紅色空心向下仍是「改善確認中的拉回」，綠色空心向上仍是「惡化確認中的反彈」。它們不代表股價即將同方向移動，也不是買進或賣出指令。

常見組合可這樣理解：

- 紅星加向上箭頭：目前累積效率高，近期仍在改善。
- 紅星加向下箭頭：目前仍是最高評等，但近期效率正在惡化，適合提高注意，不等於應立即賣出。
- 綠框「1」或綠框「2」加向上箭頭：目前累積效率仍弱，但近期正在改善，不等於已適合買進。
- 沒有箭頭：只表示未達明顯改善或惡化門檻，不代表資料一定正常、趨勢永久不變或適合繼續持有。

評等趨勢跟選股評等一樣逐交易日保存。股票清單與個股表頭顯示最新交易日的評等與趨勢；每日交易清單與技術檢視則顯示各自交易日或目前選取歷史日的狀態，因此同一畫面不同日期的圖示可能而且應該不同。前／後期只由已保存的階段與本段最高、最低值即時判斷，冷開機不必為顯示而重算歷史。箭頭描述的是策略適配效率，不是股價漲跌、技術線型方向或未來報酬預測。門檻來源、限制與後續校正方式見[適配趨勢研究與導入計畫](適配趨勢研究與導入計畫.md)及[評等趨勢的技術說明](Grade趨勢預警狀態持久化計畫.md)。

### 畫面位置與緊湊版面

- 直式股票清單、直式個股頁未開技術檢視的每日交易紀錄，以及一般寬度版面，個股價格圖示放在成交價泡泡內靠右；同日大盤圖示放在泡泡右外側；評等趨勢放在選股評等右側。
- 技術檢視會在所選日期的個股「收盤」旁顯示個股價格趨勢，並在「加權指數」旁顯示同日收盤指數與大盤價格趨勢；下方模擬績效區顯示選股評等與評等趨勢。
- 約 10 吋的緊湊橫式二欄會省略左側股群的價格與評等趨勢，每日交易清單仍保留；開啟三欄技術檢視後，每日交易清單也省略三個摘要圖示，把空間留給日期、價格、數量與持股天數。技術檢視本身仍顯示所選日期的完整資訊。

### 更新後圖示何時改變

- 盤中：Yahoo 可以更新個股當日行情，因此個股價格趨勢、評等趨勢與模擬結果可能是盤中暫態；App 不查詢或保存盤中加權指數，所以同日大盤維持無資料。
- 收盤後：取得 TWSE 正式日資料時，個股與加權指數一起補入並重算受影響結果；來源尚未完成時不自行補值。
- 大盤規則：當日正式大盤即使已在盤後補入，也只供當日畫面對照；依因果順序，它最早從下一個交易日成為「決策日前最近完整市場日」。週末、休市或缺日會向前找到最近一個完整市場交易日。

何時開始查詢正式日資料、App 保持開啟時如何自動檢查，以及來源尚未完成時如何處理，統一見[歷史價格下載](週期.md#歷史價格下載)。

### 綠框評等怎麼看

綠框「1」、「2」、「3」都是已啟用的正式評等，不包含資料尚未成熟的灰框「0」：

- **綠框「1」**跨過零分，範圍是 -5～23。例如實年報酬率 10%、平均持股 50 日，效率分數是 20；雖然仍有正報酬，但效率尚未達到紅框「1」。
- **綠框「2」**是最低 -23、低於 -5。例如實年報酬率 -10%、平均持股 100 日，效率分數是 -10。
- **綠框「3」**低於 -23。例如實年報酬率 -20%、平均持股 120 日，效率分數是 -24。

目前使用的 -23、-5、23、39 與 46 分界，都曾以相鄰數值重新回測；替代值沒有在不同股票與不同期間帶來較穩定的改善，因此維持現有分界。詳細實驗代號與結果保留在[回測規則驗證](回測規則驗證.md)。

## 如何使用評等

紅底白星表示該股在指定歷史模擬期間呈現最高一級的效率；旁邊的箭頭只補充效率近期改善或惡化，不改變紅星本身的級別。實際建立等候買賣的股群時，以完整三年模擬為主；若縮短為兩年後仍是紅底白星，再確認近半年技術線圖沒有明顯持續下滑，可作為較穩健的選股參考。

評等仍受股票樣本、回測窗口與買賣規則影響。不同期間可能轉級，回測結果也不保證未來績效；不應只因一次紅星就把單一股票的輸贏視為策略成敗。

「資金不足」警示表示模擬期間曾發生起始本金不足以買進至少一張股票，可能使模擬結果與評等失真，解讀時應先排除此項資料品質問題。
