# 使用者文件截圖流程

## 用途

本流程使用既有的 10.2 吋九年模擬裝置更新 README 介面截圖，呈現實際使用中的股群、Trade List、技術檢視，以及個股價格、加權指數與 Grade 三種趨勢圖示。畫面中的股票及模擬結果只供版面說明，不是選股推薦、固定回測樣本或規則證據。

## 固定環境

- 裝置：`simStock3 iPad 10.2-inch`，iPad 第 9 代；目前為 iPadOS 26.5。
- App：當次工作目錄已驗證的最新 App，覆蓋安裝時保留 Simulator 既有資料。
- 資料：此裝置既有的九年模擬資料，目前包含兩個股群共十檔股票；不為截圖清除、覆蓋或另建資料庫。
- 主要畫面股票：`2308 台達電`，讓四張圖能連續對照同一份 9.1 年模擬結果。
- 13 吋 `iPad Pro 13-inch (M5)` 仍是主要設計與一般功能驗證基準，但不再作為 README 這組標準截圖來源。

## 截圖前準備

1. 確認 10.2 吋 Simulator 已開機；需要換入新版 App 時只覆蓋安裝，不先刪除 App 或資料。
2. 正常啟動 App，等待任何 T/S 遷移、股價與大盤正式日資料增量更新完成。若來源尚未完成當日資料，不改造數值來填滿畫面。
3. 確認畫面沒有遷移警告、載入遮罩或更新中的進度；底部狀態應清楚顯示目前的大盤、股價、歷史補齊及 Yahoo 查詢狀態。
4. 選取 `2308 台達電` 與最新正式交易日。畫面要能看到「期間 9.1 年」；日後資料增加時可自然顯示新的年數，不為維持文字而凍結資料。

## 三種趨勢與緊湊版面

- 直式 List 與未開技術檢視的直式 Page，應顯示個股價格、同日加權指數及 Grade 三種趨勢；沒有同日正式大盤資料時，大盤圖示本來就應留空。
- 10.2 吋橫式二欄的股群側欄會省略價格與 Grade 趨勢，只保留 Grade 等級；Trade List 維持完整圖示。
- 10.2 吋橫式三欄開啟技術檢視後，Trade List 會省略三個摘要圖示；技術檢視仍顯示所選日期的個股收盤與價格趨勢、同日「加權指數」Close 與市場趨勢，以及模擬績效中的 Grade 與 Grade 趨勢。
- 淡色與原色、實心與空心的解讀，以[選股評等](選股評等.md#三種趨勢圖示)為準；截圖不可用人工方式改造階段或模擬結果。

## 標準截圖

四張圖片存入 `doc/screenshots/YYYYMMDD/`，README 同步改指向新目錄：

1. `ipad-portrait-list.png`：直式股群 List，呈現兩個股群、十檔股票、9.1 年欄位與摘要圖示。
2. `ipad-portrait-page.png`：直式個股 Page，呈現台達電表頭、9.1 年績效及完整 Trade List 圖示。
3. `ipad-landscape-page.png`：橫式二欄 Page，呈現緊湊股群側欄與完整 Trade List。
4. `ipad-landscape-technical.png`：橫式三欄技術檢視，呈現緊湊 Trade List，以及所選日期的個股行情、同日加權指數與趨勢圖示。

原始 Simulator 畫面尺寸為直式 `1620 × 2160`、橫式 `2160 × 1620`。若擷取工具把橫式像素保存成側轉的 `1620 × 2160`，應先旋轉並目視確認，再交給 README；不能只看檔名判定方向。

## 完成條件

- 四張圖片方向正確，沒有截斷、溢出、載入遮罩或警告。
- 直式、橫式二欄及橫式三欄的圖示顯示／省略符合緊湊版面規則。
- 9.1 年模擬期間、台達電 Trade 日期與技術檢視日期可互相對照；同日加權指數資料不以前一日冒充。
- README、[選股評等](選股評等.md)及畫面使用相同的三種趨勢名稱與分段解釋。
- 完成後保持 10.2 吋 Simulator 開機，停留在橫式台達電技術檢視，方便直接確認。
