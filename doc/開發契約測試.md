# 開發用升版與重算契約測試

此入口只執行既有 XCTest，不新增 App 狀態檢查、診斷報告或保存失敗注入，也不取代[發布流程](發布流程.md)、正式 Baseline 驗證或正常裝置驗收。

## 一個指令執行

先備妥**專用空白 iOS Simulator**，名稱必須以 `simStock3 Contract Tests ` 開頭；取得 UDID 後執行：

```sh
scripts/run-contract-tests.py \
  --simulator <專用裝置UDID> \
  --build-dir exports/contract-tests/DerivedData \
  --output exports/contract-tests/run-001 \
  --timeout 900
```

例如以本機已安裝的 runtime 建立專用裝置：

```sh
xcrun simctl create 'simStock3 Contract Tests local' \
  com.apple.CoreSimulator.SimDeviceType.iPad-A16 \
  com.apple.CoreSimulator.SimRuntime.iOS-26-5
```

這只建立新的空白裝置，不複製正常資料；runtime 不存在時應選擇本機已安裝且相容版本，不由入口下載。腳本不建立、抹除或刪除裝置，也不選預設裝置；完成後裝置保留，是否關機由使用者決定。正常 10.86 吋、13 吋及研究 FE32 名稱不符合要求，會在啟動／建置前拒絕。

`--output` 必須是尚不存在的新目錄，不覆寫之前結果；`--build-dir` 首次使用新目錄，後續可重用本入口建立的專用目錄。`xcodebuild test` 使用其增量建置，不額外再 build 或重跑另一套測試。固定 Debug、單一 destination、停用平行測試，不改專案建置設定或簽署設定。

只查選取清單、不啟動 Xcode 或 Simulator：

```sh
scripts/run-contract-tests.py --list
```

## 固定涵蓋範圍

精確 suite／case 名稱集中於 [contract-tests.json](../scripts/contract-tests.json)，入口每次先對照原 Swift 測試方法，再對照 `.xcresult` 中實際執行的案例。不是複製測試邏輯，也不依未來自動新增的類別方法悄悄擴大範圍。

| 既有測試類別 | 選取數 | 涵蓋契約 |
| --- | ---: | --- |
| RecalculationTests | 28 | 舊 S／T 遷移、只重算 S、dirty 範圍與恢復、人工操作保留／重驗、P10 前態、遷移閘門 |
| StockHistoryTests | 4 | 重開後仍保留待重建狀態、期間／股群變動與人工意圖 |
| HistoryCoverageTests | 4 | 正式行情完整性、Yahoo 阻擋、待更新範圍擴至整個股群 |
| MarketDataTests | 8 | 大盤版本／schema 遷移、原 OHLC 保存、正式輸入與技術結果持久化 |
| TWSEBatchContinuationTests | 6 | 續批、取消、重複回覆、失敗停止及不重抓成功月份 |

共 50 個既有案例，使用測試自建的記憶體／暫存 store；市場分批案例以 URLProtocol fixture 回覆，不下載完整行情。這不包含真實程序任意時點強制終止、保存故障注入或新策略回測。

## 結果與停止

終端列出選取名稱、階段、日誌位元組進度及每個案例的 `PASSED`／`FAILED`／`NOT-RUN`。輸出目錄保存 `summary.json`、各階段 `.log`、逐案例原始 JSON 及 `tests.xcresult`，由 Xcode 開啟後可查失敗詳情。

- `0`：Xcode 成功，所有指定案例恰好執行一次且通過，沒有意外案例。
- `1`：Xcode／測試失敗、案例漏跑／跳過／重複，或執行了非選取案例。零案例不能成功。
- `2`：設定、裝置、結果讀取或環境問題，不能確認完成。
- `124`：達總時限，或超過無日誌進度時限；`130`：被中斷。

總時限預設 900 秒、最多 1800 秒；`--stall-timeout` 預設 180 秒。沒有新日誌不算進度。逾時或中斷只停止腳本自己啟動的命令程序群，保留現場與結果，不殺其他 Simulator／Xcode 程序。腳本啟動前參數／選取錯誤直接報 `NOT RUN`／參數錯誤，不建立成功結果。

入口自身的必要正負例可單獨執行，不使用 App 或 Simulator：

```sh
python3 -B -m unittest discover -s scripts -p test_contract_runner.py
```
