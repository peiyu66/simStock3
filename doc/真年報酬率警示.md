# 真年報酬率警示

相關閱讀：[報酬率定義](報酬率.md)、[選股評等](選股評等.md)；開發與研究見[持久化設計](真年報酬率警示持久化.md)及[警示研究索引](README.md#警示恢復與承低風險)。

每日交易紀錄在「買／賣／餘」文字左側，以小圖示提醒報酬或價格轉弱。空手時也可顯示；解除或沒有圖示時仍保留等寬空間，讓圖示、買賣文字與庫存數各自上下對齊。窄視窗與價格趨勢一起隱藏，並收回圖示占位。點圖示先看報酬、恢復差距或預警保留天數；「解除條件」可展開。視窗隨字級放大，內容可上下捲動。

預警與警戒都不以[真年報酬率](報酬率.md#真年報酬率)的正負分級。正報酬因時間增加而下降，也表示資金運用效率降低。

單輪獲利或短暫回升不會降低報酬恢復參照。警示不改變選股評等、買賣或加碼，也不代表能預測某一輪輸贏。沒有圖示可能是未觸發、已解除或資料不足，不能直接解讀為安全。

## 預警

原警戒未啟動或已近期解除時，同時符合以下條件即顯示空心三角形：

- 前一交易日真年報酬率，不高於該日往前20個交易日，且低於該日往前60個交易日。
- 當日20日及60日均線乖離的Z125都小於0。

Z125衡量當日乖離相對最近125個交易日的平均位置；小於0表示相對偏弱，不等於價格必然低於均線。沿用既有技術值，需完整60日均線及125筆乖離資料（至少184筆行情），以及61筆同期間已完成模擬紀錄。

條件第一次成立就預警。其後連續第一、第二個不成立日仍保留，第三日當天解除；重新成立便重新計數。因此每次連續不成立最多多保留兩日，反覆成立時整段預警仍可能更長。保留期間的說明會標明目前條件已不成立。資料不足不沿用保留日；原警戒及恢復觀察立即優先。

近期解除後，若當日價格趨勢進入探底前期或後期，也會先預警，不直接恢復警戒。說明會區分「報酬走弱」與「價格轉入探底」；兩者同時成立時一併提示。任一條件成立都會維持預警，兩者連續三個交易日均不成立才解除；保留日仍可查看先前觸發原因。

## 警戒啟動與解除

至少有61筆同一模擬期間已完成的交易紀錄後，前一交易日真年報酬率低於往前60個交易日、且不高於往前20個交易日，加上當日價格低於60日均線、60日均線低於20個交易日前時，啟動警戒。

啟動時凍結該次往前60個交易日的真年報酬率作為解除參照，後續新低或小賺不會調降它。價格回到60日均線以上、60日均線回到20個交易日前水準以上，而且前一交易日真年報酬率達到凍結參照並高於往前20個交易日時，才完整解除。

尚未完整解除時，價格及均線已恢復、近期真年報酬率回升，並且**前一交易日評等趨勢為改善探頂**，才列為「恢復觀察」。改善拉回、惡化中的反彈或其餘階段，在尚未達近期解除時仍顯示實心警戒三角形。

價格及60日均線已恢復、近期真年報酬率回升，且符合下列任一轉強確認時，當日收盤價突破此前20筆最高收盤並站上20日均線，開始一次**突破觀察**。當下凍結此前20筆最高價、前日真年報酬率、[評等效率分數](選股評等.md#效率分數)與[累計損益](報酬率.md#累計損益)。

觀察起點算第1筆，至少連續3筆收盤高於凍結參照價及20日均線，而且價格／報酬恢復及轉強確認仍成立，才可考慮**近期解除**。解除時前日真年報酬率須高於觀察起點、累計損益不低於起點，評等效率分數不低於起點及其20／60筆前。觀察最長20筆；收盤回到參照價或20日均線以下（含相等）、缺值或到期就結束這次觀察，之後需重新符合突破條件。缺漏或零值比較基準不視為通過。

突破觀察參照在單次觀察內固定，不是初次警戒以來的最高價，也不是預測目標。解除後保存這次突破位、解除當日收盤及前日效能作為複合失效參照；原完整恢復報酬參照仍保留。若另符合預警，仍顯示空心三角形。
轉強確認：前一交易日評等趨勢為改善探頂；或當日價格高於20日及60日均線，且兩條均線的[向上延續計數](技術數值與研究原則.md#ma-days-的趨勢持續期)都大於20。此計數容許短暫反向後接續，不等於嚴格連續上升20日。均線替代確認只用於近期解除，不改變「恢復觀察」的原判定。

另一種**近期解除**方式是近期成果穩定，同時符合：

- 前一交易日的[評等效率分數](選股評等.md#效率分數)，相對其20日、60日前，退步都不超過10%。
- 前一交易日的[累計損益](報酬率.md#累計損益)，相對截至該日近60個交易日間隔內的最高值，回落不超過10%。
- 當日價格高於20日及60日均線，兩條均線的向上延續計數皆大於0。

分數差與損益回落都除以比較基準的絕對值；基準為0或資料不完整時不採此方式。負數改善也可符合，不要求先轉成正報酬。這表示近期成果相對穩定，不代表歷史虧損消失、未來損失最多10%，或每一輪買進都安全。原報酬參照仍保留；單獨以近期穩定解除時，不套用突破解除的複合失效參照。解除後不因這組條件單日不符就直接回警戒，依下列條件追蹤。

近期解除後，若價格跌破20日均線、前日真年報酬率不高於往前20個交易日，且前日評等趨勢已離開改善探頂，三項同時成立即再度警戒；原啟動條件重新成立也會再警戒。價格探底造成的預警，不另強制觸發這項再警戒。原完整解除條件成立時，才清除這次警戒的報酬參照與價格高點。這項補充仍是資訊提醒，不會自動拒買或賣出。

**突破解除另有配套判斷**：當日收盤低於20日均線，且低於解除價或凍結突破位；前日真年報酬率低於解除時；前日評等效率分數或累計損益也低於解除時。三個面向同時成立，第1筆預警，連續第2筆再警戒；中斷或資料不足則重新計數。預警仍需前述成熟有效資料；單獨跌破一個價位不成立。若完整解除或原再警戒條件已成立，優先依原條件轉換，不等待第二筆。再警戒當天先顯示警戒，恢復觀察從之後的紀錄重新判讀。

新增原因與原報酬／價格探底預警可同時顯示；三日移除預警要所有原因均不成立。這可縮短部分解除失敗的空窗，但不能保證避免假解除或新增切換，完整正反例見[警戒生命週期研究](警戒生命週期研究結果-20261008.md)。

差距以百分點顯示，不是本金虧損率；真年報酬率本身包含模擬經過時間的年化效果。警示結果會隨模擬保存，冷啟動直接讀取，不從頭重建。更新行情、改變模擬設定或升級資料規則時，才按受影響範圍更新；首次升級需要建立既有歷史的警示資料。改變模擬起始日或重算歷史，警示也會隨原始結果重新建立。歷史待重算、資料不足或使用無限加碼時，不顯示此警示。

本指標先以富邦媒案例校準後採用為資訊提醒，後續暫採國泰金案例形成的較嚴近期解除條件；可對其他股票依相同公式顯示，預警另以完整樣本庫統計後採用，但不代表能預測未來虧損；[研究與採用紀錄](回測規則驗證.md#true-annual-warning-ui-adoption-20260914)保留正反例及驗證界線。
