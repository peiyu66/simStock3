## 目的與範圍

保留每日行情四類圖示原解說，在彈窗補上足以理解圖示的 2～5 項數值，省去開啟技術側欄。沿用 iPad 與 `IconExplanation`；不新增 iPhone 支援、策略、schema、診斷、歷史重算或 T/S 語意變更。正常 Simulator 不替換，以專用 UI 測試裝置驗證。

使用者已核准依序完成下列批次；先交付畫面供確認，確認後才提交本次修改。commit／push 仍依當次明確授權及既有發布流程處理，不以本計畫新增永久禁令，也不把 UI 工作推定為正式裝置安裝或 App Store 發布。

## 資料與日期

- 每日行情解說使用該列 `Trade`，明列實際日期與來源；清單、側欄與技術檢視只顯示圖示，不再提供點按解說。
- 評等及累計績效是模擬起點至所選日的完成後結果，不是交易決策前評等。不得以最新 Stock 績效解釋歷史圖示。
- 警示的前日報酬沿用 `storedAnnualWarning`，與當日價格／均線分列；不在 UI 重建警示引擎。
- 大盤只取 `MarketDay.fetchSameDay`，缺同日資料不往前或往後補位。
- Stock 本金、加碼設定與資金不足摘要標為目前設定／整段提醒；不宣稱發生在該歷史日。
- 缺值顯示「— · 資料不足」，待重算顯示「待重算」。保留原始行情與尚未完成的技術／模擬結果之區別，不以預設 0 冒充有效結果。

## 既有覆蓋限制

只有每日行情四個資訊圖示及警示圖示點按開窗；操作圖示長按開窗、點按執行原功能。盤整、中性、冷卻及資料不足部分狀態不顯示箭頭；緊湊布局也會隱藏部分趨勢。通用技術卡片的開高低漲跌停符號目前未接窗；`.sidebar/.removal` 只定義未使用。不能把未接線項目稱作現有彈窗。本次不擴大隱藏圖示或新增入口的設計。
