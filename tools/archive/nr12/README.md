# NR12 長期套牢研究工具封存

本目錄封存 NR12 在採用 `S-T02g` 前使用的兩支診斷工具。它們不是日常回測 runner，也不代表目前仍排隊中的研究任務；保留目的只是重現「長期等待是否值得」的研究方法，供未來重新檢查持股日數、ROI 邊界或加碼限制時參考。

- `nr12_waiting_value_study.py`：從固定窗口 DecisionBase 建立 90／150／240 日檢查點，統計後續 20／60／120 個交易日的恢復、賣出與加碼情形。
- `nr12_waiting_cost_study.py`：延伸至 90／150／240／360／480 日，衡量檢查點到實際賣出的 ROI 交換與等待日數。

兩支工具的分類條件只使用檢查日以前資料，但後續 ROI、實際賣出與等待日數是事後結果，只能形成候選假設，不能直接當成可交易訊號或候選分數。程式內的 DecisionBase 路徑固定指向 Baseline v14／S26／T2-S33；日後若要重用，必須先確認資料表 schema、規則版本與比較目的，不能直接套用舊路徑得出現行結論。

正式採用結果與設計判讀記錄在 [`doc/回測規則驗證.md`](../../../doc/回測規則驗證.md#nr12)。
